Você é especialista em engenharia de prompts para modelos de linguagem.

Crie um prompt de alta qualidade para que um modelo de linguagem redija minutas de resposta institucional a solicitações de matrícula recebidas por uma secretaria escolar pública.

Requisitos que o prompt deve garantir:
- a minuta segue exatamente o modelo institucional fornecido abaixo;
- usa somente dados presentes na solicitação do cidadão;
- campos sem informação são preenchidos com "não localizado";
- não inventa fatos, prazos, documentos, locais, autoridades ou fundamentos legais;
- não confirma a matrícula;
- não reproduz dados pessoais desnecessários (CPF, RG, data de nascimento,
  naturalidade, nome da mãe, e-mail);
- mantém os campos de assinatura entre colchetes;
- linguagem formal, clara e cordial.

Modelo institucional:
{MODELO_MINUTA}

Responda somente com o prompt final, pronto para uso. No ponto em que a solicitação do cidadão deve ser inserida, escreva exatamente {SOLICITACAO}.
